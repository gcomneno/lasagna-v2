# Local-model value experiment protocol

Status: FROZEN — PRE-EXECUTION PROTOCOL

## Research question

At matched reconstruction distortion, does Lasagna 2's adaptive segmentation
plus local predictor selection reduce encoded rate enough to repay its
structural cost relative to simpler predictive architectures?

The experiment tests the architectural hypothesis:

```text
better local structure
        ↓
smaller / more compressible residual representation
        ↓
rate saving
        ↓
saving > added segment / predictor / block metadata
```

The experiment is not a comparison against gzip, zstd, Gorilla or other
external codecs. Those questions are covered by separate studies.

This experiment isolates the value of Lasagna's own structural machinery.

## Hypothesis

Primary hypothesis:

```text
Within the frozen sampled rate-distortion grid and its common observed
distortion range, adaptive segmentation + local predictor selection achieves
lower total V2 bits/sample than the best eligible whole-series linear or
fixed-64 linear baseline on the external qualification corpus.
```

Failure to satisfy the frozen decision rule means that this experiment does
not provide sufficient evidence for that empirical advantage. It does not
establish that structural prediction can never repay its cost.

A negative, mixed or insufficient-coverage result is valid evidence.

## Frozen codec controls

Every evaluated architecture SHALL use:

```text
wire format       = V2
residual coding   = varint
Q_MIN             = 1e-6
numeric contract  = current production-qualified V2 contract
```

No architecture-specific residual codec is permitted.

No dataset-specific parameter tuning is permitted.

Every architecture SHALL be evaluated at exactly:


```text

```

Rules:

```text

```

### A2 — fixed_auto

Purpose:

```text
isolate value of local predictor selection

```

Rules:

```text

```

### A3 — adaptive_linear

Purpose:

```text
isolate value of adaptive segmentation
without local predictor selection
```

Rules:

```text
segment_mode        = adaptive
min_segment_length  = 32
max_segment_length  = 128
mse_threshold       = 0.5
predictor            = linear
```

### A4 — adaptive_auto

Purpose:

```text
full current Lasagna structural architecture
```

Rules:

```text
segment_mode        = adaptive
min_segment_length  = 32
max_segment_length  = 128
mse_threshold       = 0.5
predictor            = auto
```

A4 is the full structural architecture under test. It does not receive a
privileged role in generating primary distortion targets.

Operational semantics are frozen as follows:

```text
A1 / A2 fixed boundaries
    = identical fixed-64 segment boundaries

A3 / A4 adaptive boundaries
    = identical boundaries generated by the linear predictor

auto selection
    = choose among mean / linear / random-walk using the current
      post-quantization reconstruction-MSE rule before V2 metadata rounding

V2 final residuals
    = recomputed after binary32 segment-metadata rounding
```

The experiment SHALL assert A1/A2 boundary equality and A3/A4 boundary
equality for every evaluated dataset/configuration pair.

## Measurements

Every architecture / dataset / C_Q evaluation point SHALL report:

```text
dataset
evidence_group
architecture
C_Q
Q_MIN
n_samples

encoded_bytes
bits_per_sample
compression_ratio

mse
rmse
max_abs_error

segment_count
mean_segment_length
min_segment_length_observed
max_segment_length_observed

mean_predictor_segments
linear_predictor_segments
rw_predictor_segments

global_and_context_bytes
segment_metadata_bytes
residual_block_metadata_bytes
residual_payload_bytes
structural_bytes

encode_time_ms
decode_time_ms
```

The byte decomposition SHALL reconcile exactly with the frozen V2 layout.

Let:

```text
H   = serialized UTF-8 context length
S   = segment count
L_i = declared residual payload length of residual block i
```

Then:

```text
global_and_context_bytes
    = 28-byte file header
    + H-byte context
    + 16-byte residual-section header

segment_metadata_bytes
    = 32 * S

residual_block_metadata_bytes
    = 12 * S

residual_payload_bytes
    = sum(L_i)

encoded_bytes
    =
      global_and_context_bytes
    + segment_metadata_bytes
    + residual_block_metadata_bytes
    + residual_payload_bytes

structural_bytes
    = encoded_bytes - residual_payload_bytes
```

The residual-section header SHALL NOT be omitted from accounting.

The parser SHALL verify that the final parsed byte offset equals
`len(encoded)` exactly. Unexplained remaining bytes SHALL NOT be assigned to
payload.

All architectures SHALL use identical `TimeSeries` context values so context
size cannot become an architecture-dependent variable.

If exact decomposition cannot be derived from the frozen V2 stream, the
experiment SHALL fail rather than report estimated byte accounting.

## Matched-distortion rule

Primary distortion targets SHALL be architecture-neutral.

For each dataset, first collect the measured RMSE values from:

```text
A0 whole_linear
A1 fixed_linear
A4 adaptive_auto
```

Define the common observed distortion interval:

```text
D_min =
    max(
        minimum observed RMSE of A0,
        minimum observed RMSE of A1,
        minimum observed RMSE of A4
    )

D_max =
    min(
        maximum observed RMSE of A0,
        maximum observed RMSE of A1,
        maximum observed RMSE of A4
    )
```

If:

```text
D_min > D_max
```

then:

```text
PRIMARY_COVERAGE_STATUS = INSUFFICIENT_COVERAGE
```

and the primary empirical-advantage claim is NOT SUPPORTED for the experiment.

Otherwise, construct the target set as the sorted unique union of the measured
RMSE values from A0, A1 and A4 that lie in the closed interval:

```text
[D_min, D_max]
```

Target equality and deduplication SHALL use the full-precision measured RMSE
values used by the matcher. Human-readable CSV formatting SHALL NOT determine
target identity.

For each unique target `D` and each architecture `A`:

1. consider only evaluated points of `A` with:

```text
RMSE <= D
```

2. among those eligible points, select the point with minimum:

```text
encoded_bytes
```

`bits_per_sample` SHALL then be derived from the selected integer encoded byte
count and sample count.

3. ties SHALL be resolved by:
   - lower RMSE;
   - then lower max absolute error;
   - then lower C_Q;
   - then stable architecture/configuration identifier.

This envelope selection rule applies to A4 as well as every baseline.

For every primary target, A0, A1 and A4 SHALL all have an eligible point.
Failure of that invariant is:

```text
PRIMARY_COVERAGE_STATUS = INSUFFICIENT_COVERAGE
```

and the primary empirical-advantage claim is NOT SUPPORTED.

A2 and A3 eligibility SHALL be reported independently for descriptive
architectural comparisons and SHALL NOT affect primary target coverage.

No interpolation between C_Q points is permitted. The conclusions therefore
apply only to the sampled achievable configurations.

No architecture receives credit for a smaller stream obtained by exceeding the
common distortion budget.

## Primary comparison

The primary comparison is:

```text
A4 adaptive_auto
vs
best eligible whole-series linear or fixed-64 linear V2 baseline
under the same RMSE budget
```

where:

```text
primary baseline family = {A0 whole_linear, A1 fixed_linear}
```

For each unique primary target, select the lower-rate eligible point between A0
and A1 using the same tie-break hierarchy.

If A0 and A1 remain tied after RMSE, max-error and C_Q tie-breaks, use the
stable architecture identifier as the final deterministic tie-break.

For each primary target:

```text
rate_ratio =
    A4_bits_per_sample
    /
    best_primary_baseline_bits_per_sample
```

Interpretation:

```text
rate_ratio < 1  => A4 uses fewer bits
rate_ratio = 1  => tie
rate_ratio > 1  => simple baseline uses fewer bits
```

Materiality bands are frozen as:

```text
rate_ratio <= 0.95  => MATERIAL_WIN
0.95 < ratio < 1.05 => PRACTICAL_TIE
rate_ratio >= 1.05  => MATERIAL_LOSS
```

Exact ratios SHALL also be reported.

## Architectural decomposition

The experiment SHALL additionally compare:

```text
A2 vs A1
```

to estimate the value of local predictor selection under identical fixed
segmentation;

and:

```text
A3 vs A1
```

to estimate the value of adaptive segmentation with the predictor held fixed.

Finally:

```text
A4 vs A2
A4 vs A3
```

shall characterize whether combining the two mechanisms provides additional
benefit beyond either mechanism alone.

These comparisons are descriptive. They SHALL NOT be interpreted as strict
causal estimates if segment boundaries or quantization interactions differ.

## Dataset-level summary

For each external dataset, report across all unique primary targets:

```text
number of primary targets

number covered by A1
number covered by A4
number with complete primary coverage
material wins
practical ties
material losses
non-loss fraction
median rate_ratio
best rate_ratio

```

The dataset median SHALL use the conventional median; for an even number of
ratios it is the arithmetic mean of the two middle sorted ratios.

A dataset with incomplete primary coverage SHALL be marked
`INSUFFICIENT_COVERAGE` and SHALL prevent support for the primary claim.

Internal datasets SHALL use the same report but remain secondary evidence.

## Cross-dataset decision rule

The experiment supports the following narrowly scoped statement only when all
frozen gates pass:

> On the eight frozen external qualification series, within the common observed
> distortion range and frozen seven-point quantization grid, adaptive_auto
> shows an empirical total-V2-rate advantage over the best eligible
> whole-series linear or fixed-64 linear baseline, including all wire
> overhead.

Support requires all of the following:

```text
0. all eight external datasets have complete primary-target coverage;

1. at least 6/8 datasets have median rate_ratio <= 0.95;

2. the geometric mean of all eight positive, finite dataset median ratios
   is <= 0.95;

3. no more than 1/8 datasets has median rate_ratio >= 1.05;

4. at least 75% of unique primary external dataset/target observations
   are not MATERIAL_LOSS;

5. byte decomposition demonstrates that the observed rate advantage remains
   after all segment and residual-block structural overhead is included.
```

The geometric mean SHALL be computed exactly as:

```text
exp(sum(log(dataset_median_ratio)) / 8)
```

using one positive, finite median from every external dataset.

Gate 4 counts one observation per unique `(dataset, distortion_target)` pair.
It SHALL NOT count one observation per architecture row.

Because datasets can contain different numbers of unique primary targets,
gate 4 weights datasets by their target counts. Each dataset's individual
non-loss fraction SHALL therefore also be reported.

If coverage is incomplete, any median is non-finite/non-positive, or any gate
fails, the empirical-advantage claim is NOT SUPPORTED.

A mixed result SHALL be reported as mixed rather than converted into a weaker
post-hoc success criterion.

A mixed result SHALL be reported as mixed rather than converted into a weaker
post-hoc success criterion.

## Pareto analysis

For every dataset, the complete evaluated rate-distortion points SHALL also be
reported.

Pareto frontiers SHALL be reported both:

```text
per architecture
pooled across A0-A4
```

The experiment SHALL identify the Pareto frontier in:

```text
(bits/sample, RMSE)
```

A point is dominated when another point has:

```text
bits/sample <= candidate bits/sample
AND
RMSE <= candidate RMSE
```

with at least one strict inequality.

Matched-distortion analysis is primary.

Pareto-frontier analysis is complementary and SHALL NOT replace the frozen
decision rule.

## Non-goals

This experiment does not:

- compare Lasagna with external codecs;
- change the production defaults;
- change the V2 wire format;
- add predictors;
- change residual coding;
- optimize parameters per dataset;
- prove universal codec superiority;
- promote a new segmentation strategy.

Any production change requires a separate decision after this experiment.
